# Original fictional cast

Current `avatar-v2.png` portraits and `cutout-v2.png` transparent stage assets were created with built-in AI image generation, following organizer permission confirmed by the human. See [the prompt set and provenance](../../docs/ART-PROMPTS.md).

Earlier `ref.png` portraits are procedural stand-ins produced by `scripts/create-placeholder-art.py`, using Python's standard library. They were used for the initial feasibility spike and are retained for reproducibility.

Character references and transparent art are still images. Only real Higgs Avatar outputs demonstrate lip animation; playback labels distinguish those from audio-only performances.
